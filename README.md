# Projet R Shiny - Dashboard Interactif

## Description

Ce projet consiste à nettoyer un dataset public et créer un dashboard interactif avec R Shiny pour visualiser les données en temps réel. L'objectif est de maîtriser le cycle complet : exploration, nettoyage des données, gestion des outliers, et développement d'une interface web interactive pour présenter les résultats.

## Structure du projet

```
Projet_R_2_Oms/
├── README.md
├── data/
│   ├── dataset_brut.csv      # Données originales
│   └── dataset_clean.csv     # Données nettoyées
├── scripts/
│   ├── nettoyage.R          # Script de nettoyage
│   └── app.R                # Dashboard Shiny
├── rapport.pdf              # Rapport de synthèse
└── presentation.pptx        # Présentation du projet
```

## Étapes du projet

1. **Exploration du dataset** - Analyse de la structure et identification des problèmes
2. **Nettoyage des données** - Traitement des valeurs manquantes et outliers
3. **Dashboard Shiny** - Création d'une interface interactive
4. **Synthèse** - Rapport et présentation des résultats

## Technologies utilisées

- **R** - Langage principal
- **Shiny** - Dashboard interactif
- **ggplot2** - Visualisations
- **dplyr** - Manipulation des données
